# Detention, Mapped

A responsive, interactive map of ICE detention facility records reported in California, Florida, and Texas.

## Open the page

Open [index.html](./index.html) locally or serve this repository as a static site. It uses Leaflet and OpenStreetMap tiles.

## Data and limitations

The mapped inventory uses FY2026 facility statistics through July 2026 from Asylum Tracker, which compiles ICE detention management data. That inventory does not certify that every location is open today. Pins are approximate city locations, not verified facility street addresses. Check the official ICE facility directory for current contacts.

- [California facility records](https://asylumstats.com/ice/facilities/state/california)
- [Florida facility records](https://asylumstats.com/ice/facilities/state/florida)
- [Texas facility records](https://asylumstats.com/ice/facilities/state/texas)
- [Official ICE detention facility directory](https://www.ice.gov/detain/detention-facilities)

The map includes each facility record in those three FY2026 state inventories (8 California, 17 Florida, and 27 Texas records). A facility record may refer to a local jail or a brief-hold site, not only a dedicated immigration detention center.
